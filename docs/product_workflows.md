# Product Workflows

## Admin Workflow

1. Open Field Type Library.
2. Review Starter Catalog.
3. Add new type only when operationally needed.
4. Activate/deactivate types safely.

## Template Builder Workflow

1. Enter template name.
2. Add fields with label and code.
3. Select type from approved list.
4. Mark required fields.
5. Save template.

## Encoder Workflow

1. Choose template.
2. Fill required fields.
3. Submit record.
4. Confirm success receipt.

## Records Review Workflow

1. Choose template.
2. Review records table.
3. Filter/search.
4. Export CSV or print.
