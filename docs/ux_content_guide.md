# UX Content Guide (Staff-First)

## Language Rules

- Use plain words.
- Avoid technical terms like schema, key, payload in UI labels.
- Use action-focused button labels.

## Label Conventions

- "Field Label" (shown to staff)
- "Field Code" (system reference, with helper text)
- "Type" as dropdown with short description

## Error Message Style

- State problem clearly.
- Explain how to fix.
- Keep one sentence if possible.

Examples:

- "This field is required. Please enter a value."
- "Choose a valid type from the list."
- "This template cannot be changed because records already exist."

## Success Message Style

- Confirm action and context.
- Example: "Record saved under Maintenance Logs."
